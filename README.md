# 💅 Manicuras PRO

Sitio web moderno, elegante y totalmente responsivo para un salón de belleza especializado en manicura, uñas acrílicas, nail art y tratamientos de spa para uñas.

---

## ✨ Descripción

Manicuras PRO es una landing page diseñada para promocionar servicios de cuidado y diseño de uñas. El objetivo principal es ofrecer una experiencia visual atractiva que permita mostrar servicios, diseños realizados, testimonios de clientes y facilitar la reserva de citas mediante formulario o integración con WhatsApp.

## 🔍 Optimización SEO

Agregar dentro de la etiqueta `<head>`:

```html
<meta name="description" content="Centro profesional de manicura, uñas acrílicas, nail art y spa de uñas.">

<meta name="keywords" content="manicure, uñas acrílicas, nail art, spa de uñas, salón de belleza">

<meta property="og:title" content="Manicuras PRO">

<meta property="og:description" content="Diseños exclusivos y cuidado profesional para tus uñas">

<meta property="og:type" content="website">
```

## 📲 Integración con WhatsApp

Para habilitar reservas directas mediante WhatsApp, reemplazar el número de ejemplo por tu número real:

```html

```

```html

```
